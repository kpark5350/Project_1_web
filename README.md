## Project Description

Recipe Studio is a simple recipe website that I created for my CSC 4370 Project 1. The website helps users find different food recipes and learn how to make them.

I wanted to make the website simple, clean, and easy to use.

## Features

- Home page with featured recipes
- Six different food recipes
- Recipe details with ingredients and cooking steps
- Short background stories about recipes
- About and Team Introduction sections
- Responsive design for desktop, tablet, and mobile
- CSS hover effects, transitions, and animations

## Technologies Used

- HTML
- CSS
- JavaScript
- CSS Grid and Flexbox
- CSS Media Queries

## How to Run

1. Download the project files.
2. Open `index.html` in a web browser.
3. Use the navigation menu to explore the website.

## Design Decisions

I used simple colors and a clean layout because I wanted the website to be easy to read.

I used CSS Grid for recipe cards and Flexbox for navigation and other layouts.

I also added small animations and hover effects to make the website more interactive.

I made the website responsive so it works on different screen sizes.

## Story Pack

For my extension pack, I selected Story Pack. I added short background stories to the recipes so users can learn a little more about the food.

## Testing

I tested the navigation, recipe cards, and different screen sizes. I also checked the layout, text, and hover effects.

## Project Information

This is a solo project, and I worked on the website by myself.
